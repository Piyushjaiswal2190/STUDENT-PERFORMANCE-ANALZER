
# Project Statement
## 1. Problem Statement

Managing student academic performance manually can make it difficult to calculate averages, identify weak subjects, monitor attendance, compare class performance, and maintain student records consistently.

The **Student Performance Analyzer** provides a simple Python-based solution for storing student records and generating useful academic performance reports. It reduces repetitive calculations and organizes student information using a text-file-based storage system.

## 2. Scope of the Project

The project covers basic student academic record management and analysis.

The scope includes:

- Adding student records
- Storing marks for four subjects
- Storing attendance percentage
- Searching student records
- Updating marks and attendance
- Deleting student records
- Calculating total and average marks
- Finding highest and lowest marks
- Assigning grades and grade points
- Providing subject-wise and overall feedback
- Identifying weak subjects
- Generating class performance statistics
- Generating subject performance statistics
- Generating pass/fail information
- Creating a rank list
- Displaying attendance information
- Identifying top performers
- Creating a backup of student data

The current version is a console-based application and stores data in text files rather than a database.

## 3. Target Users

The target users include:

- Students who want to review their academic performance
- Faculty members who want to maintain basic student performance records
- Class representatives who need simple class-level performance information
- Beginners learning Python, functions, loops, conditional statements, and file handling

## 4. High-Level Features

### Student Management
- Add student
- Search student
- View student report
- Update marks
- Update attendance
- Delete student

### Performance Analysis
- Total marks
- Average marks
- Highest marks
- Lowest marks
- Grades
- Grade points
- Weak-subject identification
- Overall feedback
- Study plan

### Class Reports
- Class average
- Highest performer
- Subject performance
- Pass/fail report
- Rank list
- Attendance report
- Top three performers

### Data Management
- Permanent storage in `students.txt`
- Updating stored records
- Backup through `students_backup.txt`
